# Rogue
Rogue 1980 adaptation for C++ with [SGEL](https://github.com/fabiomijango/SGEL) implementation

Procedural dungeon generation, turn-based like gameplay and roguelike mechanics, all in a simple C++ implementation.

# How to run
1. Clone the repository
2. Use the build script to automatically download dependencies and build the project
```
bash ./build.sh
```
3. Run the program with the run script
```
bash ./run.sh
```
